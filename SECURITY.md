# Security policy

## Supported versions

Security fixes are currently provided for the latest version on the `main`
branch. Older releases may not receive fixes.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Contact the
repository owner privately through the security contact configured on GitHub,
or by direct message to the maintainer, with:

- a description of the issue and its impact;
- reproduction steps or a proof of concept;
- affected versions and macOS versions; and
- any suggested mitigation.

CalendarBar contains no networking code and reads calendar data through
EventKit. Do not include real calendar contents, screenshots, or personal data
in a report.
